# 사용량 집계 서버 붙이기

한 번만 하면 되고, 대략 15분 걸립니다. **가입 → 붙여넣기 → 주소 알려주기** 세 단계입니다.

---

## 1단계. Cloudflare 무료 가입

<https://dash.cloudflare.com/sign-up> 에서 이메일로 가입합니다. 카드 등록은 필요 없습니다.

## 2단계. 저장 공간(KV) 만들기

1. 왼쪽 메뉴에서 **Storage & Databases → KV** 로 들어갑니다.
2. **Create a namespace** 를 누릅니다.
3. 이름은 `issue-radar-stats` 로 하고 저장합니다.

> 방문 기록이 담기는 곳입니다. 하루 1,000건까지 무료인데 우리는 수십 건 쓰므로 계속 무료입니다.

## 3단계. 서버(Worker) 만들기

1. 왼쪽 메뉴에서 **Compute (Workers) → Workers & Pages** 로 갑니다.
2. **Create → Start with Hello World! → Get started** 를 누릅니다.
3. 이름을 `issue-radar-stats` 로 하고 **Deploy** 를 누릅니다. (내용은 아직 아무거나 괜찮습니다)
4. 배포가 끝나면 **Edit code** 를 눌러 편집기를 엽니다.
5. 편집기에 원래 있던 내용을 **전부 지웁니다.** (편집기 안을 클릭 → `Ctrl+A` → `Delete`)
6. 아래 파일의 내용을 **전부 복사해 붙여넣습니다.** (`Ctrl+V`)

   ```
   C:\Users\Hhome\Desktop\Claude\daily-issue-radar\worker\stats-worker.js
   ```

   > **파일 여는 법** — 위 경로를 파일 탐색기 주소창에 붙여넣거나,
   > `바탕화면 → Claude → daily-issue-radar → worker` 폴더에서 `stats-worker.js` 를
   > **마우스 오른쪽 클릭 → 연결 프로그램 → 메모장** 으로 엽니다.
   > 메모장에서 `Ctrl+A`(전체 선택) → `Ctrl+C`(복사) 하면 됩니다.

7. 오른쪽 위 **Deploy** 를 누릅니다.

## 4단계. 저장 공간과 비밀번호 연결

Worker 화면에서 **Settings** 탭으로 갑니다.

**(1) 저장 공간 연결** — `Bindings` → `Add` → **KV namespace** 선택
- Variable name: `STATS` ← **반드시 이 이름이어야 합니다**
- KV namespace: 2단계에서 만든 `issue-radar-stats` 선택

**(2) 비밀번호 설정** — `Variables and Secrets` → `Add` → 종류를 **Secret** 으로 선택
- Variable name: `STATS_PASSWORD` ← **반드시 이 이름이어야 합니다**
- Value: 원하는 비밀번호 (예: `radar2026`)

둘 다 넣고 **Deploy** 를 눌러 다시 배포합니다.

## 5단계. 주소 알려주기

Worker 화면 위쪽에 이런 주소가 보입니다:

```
https://issue-radar-stats.○○○.workers.dev
```

이 주소를 알려주시면 사이트에 연결하겠습니다.
(직접 하시려면 `assets/usage.js` 9번째 줄의 `var STATS_API = "";` 안에 그 주소를 넣고 저장하면 됩니다. **끝에 `/` 는 빼세요.**)

---

## 잘 됐는지 확인하는 법

브라우저에서 `https://주소/stats?key=설정한비밀번호` 를 열어보세요.
숫자가 들어있는 글자들이 나오면 성공입니다. `unauthorized` 가 나오면 비밀번호가 다릅니다.

## 통계 보는 법

사이트 맨 아래 "데일리 이슈 레이더 — 오늘, 여론은 어디를 향했나" 문구 **오른쪽 끝의 작은 점(·)** 을 누르면
비밀번호 창이 뜹니다. 주소 뒤에 `#usage` 를 붙여도 열립니다.

## 무엇이 기록되나요

기기마다 부여한 **무작위 번호**(예: `8318c28a...`)와 **날짜·방문 횟수**만 저장됩니다.
IP 주소, 이름, 어떤 기사를 봤는지는 저장하지 않습니다. 기록은 400일 뒤 자동으로 지워집니다.

## 나중에 더 자세히 보고 싶어지면

`stats-worker.js` 에 기록 종류만 추가하면 됩니다. 그동안 쌓인 데이터는 그대로 유지되며,
탭별 사용률·기사 클릭수 같은 지표를 나중에 얹을 수 있습니다.
